# 思源聊天抓取（Edge / Chrome）

这是思源本地插件 1.2.0 的网页抓取配套扩展。MCP 插件自身没有 ChatGPT 全量历史接口，所以网页端需要一次安装；Codex 桌面端不需要此扩展。

## 安装

1. 解压配套扩展 ZIP，或下载源码中的 `plugins/siyuan-local/browser-extension/` 文件夹。
2. 打开浏览器“扩展 → 管理扩展”，开启开发人员模式，选择“加载解压缩的扩展”，选择包含 manifest.json 的 browser-extension 文件夹。
3. 将“思源聊天抓取”固定到浏览器工具栏。

扩展只申请 activeTab、scripting 和 downloads。activeTab 仅在点击扩展后临时授权当前页；没有全站后台访问权限、Cookie 权限或登录凭据读取功能。此 ZIP 是源码侧载包，尚未上架扩展商店。

## 抓取和保存

1. 打开需要保存的具体 ChatGPT 对话，等待回复生成结束。
2. 点击扩展的“抓取当前对话”，保持面板打开；它会滚动聊天以加载文字历史并下载消息图片，然后恢复原滚动位置。
3. 核对最早、最后一条文字消息，与对话一致后勾选确认，点击导出 JSON。
4. 在本机桌面宿主的聊天中选择思源插件，告诉它导出文件的绝对路径，以及目标笔记本与文档路径，要求保存原文或摘要。插件先预览，再由你确认写入。

抓取当前选中分支的页面文字和可下载的图片文件。网页渲染后的文字不等于后台原始 Markdown；折叠内容、工具详情、非图片附件和其他分支不会自动展开或复制。无法判断后台是否还有未加载内容，因此需要你核对首尾；不能把本功能称为全账号导出。临时聊天暂不支持。页面结构变化、缺失轮次、正在生成、切换对话和超时会停止导出，避免冒充完整记录。

导出文件包含聊天文字，请保存在你选择的位置。扩展不上传数据，插件只在确认后将内容写入本机思源。

图片字节随 JSON 导出；同内容去重，不缩放或重新编码。网页只保证保存页面提供的版本，只有缩略图时无法保证原始分辨率。任一图片下载失败会显示缺失项并禁用完整导出，不会用图片说明冒充文件。图片上限为单图 20 MiB、合计 100 MiB、来源 200 个，JSON 上限 144 MiB。导入后由本机插件确认上传到思源 assets，并替换引用。已装旧版扩展时，请将文件夹替换为 1.2.0 后在扩展管理页面重新加载。
