# 初次配置

1. 解释此包使用 Windows 本地 MCP 进程。用户需要支持本地插件的桌面宿主、Node.js 22 或更新版本、运行中的思源。账号安装链接保存插件包，不托管服务；普通网页或手机不能启动这个 Windows 进程。
2. 打开插件详情页的设置，API 地址默认 `http://127.0.0.1:6806`。仅允许 `localhost`、`127.0.0.1`、`[::1]`，不能填远程地址。
3. 点击“配置地址和 API Token…”打开本机设置窗口，密码框输入思源 token。token 可在思源“设置 → 鉴权 → API token”取得；旧版本可能位于“关于”。不要要求用户在聊天中发送 token。
4. 若宿主未渲染结构化设置，调用模型可见的 `siyuan_configure`，由插件本地 MCP 进程打开窗口。`settings.configure` 是仅供设置界面的入口，模型可能无法发现它。不要用代理沙箱的 shell 后台启动配置脚本并声称窗口已显示；沙箱桌面可能对用户不可见。工具不可用时先重新加载或更新插件，仍不支持时让用户在资源管理器中双击解压后的 `Configure.cmd`。同一 Windows 用户的本地配置可由安装后的服务读取。
   配置窗口标题为 `SiYuan Local`，API 地址下方的 `API token` 输入框是密码框。取消或请求中止不保存；窗口已打开时不重复启动。只有用户看到窗口或完成保存后，才报告弹窗已成功显示。
5. 调用 `siyuan_status`，再调用 `siyuan_list_notebooks` 验证只读连接。失败时检查思源是否打开、地址端口、token 和 Node 是否可用。不要用写入来测试连接。
6. 提供一个用户指定关键词的搜索示例。工具不可发现时需要宿主重新加载插件；不得声称已经完成运行验证。
